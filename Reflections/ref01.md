# Module01 Reflection

## My Take-away

Module01 gave me my first practical experience with databases and the portfolio workflow. I learned how to use GitHub, `uv`, SQLite, Python, and Datasette.

My biggest take-away is “verify before you trust.” I learned that I should not simply trust an LLM-generated SQL query. I need to run it and check the actual result.

I also learned the difference between an embedded database and a client/server database, and why SQLite is useful for local applications.

## What Was Good?

I liked working with real telemetry data instead of only learning database concepts from slides. Creating the SQLite database, running SQL queries, and checking the data with Datasette helped me understand how the different tools work together.

Setting up my GitHub portfolio was also useful because I learned how to organize my work and use Git.

## What Was Difficult?

The most difficult part was working with the terminal and SQLite commands. Sometimes I had problems with file paths, database commands, and PowerShell.

At the beginning, I was also not familiar with how GitHub, Python, CSV files, SQLite, and Datasette were connected. Solving these problems helped me become more confident with the tools.

## Struggling and Exploration

During the work, I had some problems loading and checking the telemetry data. I had to test different commands and check the results carefully.

These struggles were useful because I learned that when something does not work, I should investigate the problem instead of giving up.

## Interaction with Peers

Working with my group was helpful. During the class, we discussed problems and shared ideas with each other.

My friend Sebastian helped me clone the template from the professor's GitHub repository at the beginning. This was valuable because I was still learning how GitHub and repositories worked.

The discussions with my group also helped me understand tasks when I was stuck.

## Help and Extra Work

I received help from my group, especially when I had problems with GitHub and the course setup. I also spent extra time troubleshooting the terminal, SQLite, Python, and Datasette.

I completed the telemetry database, SQL queries, Python work, Datasette exploration, and documentation for my portfolio.

## Overall Reflection

Module01 gave me a good foundation for the following database modules. I learned that database work is not only about getting an answer. I also need to test, verify, and document my work.

The most important lesson I want to remember is: “Do not just trust that it works — verify it.”
